01O que este sistema faz

Antes, atualizar um preço obrigava a abrir e corrigir cada ficha técnica, uma a uma. Agora atualiza apenas o Preçário.

Se o preço do abacate subir, o sistema atualiza o guacamole, todos os pratos que levam guacamole, e recalcula o food cost de cada um deles.

A regra de ouro Os preços escrevem-se só no Preçário. Nunca dentro das fichas técnicas — o que lá escrever será substituído na atualização seguinte.

02Atualizar preços — o dia-a-dia

  1. Abra o Preçário Na pasta do sistema:
    docs\kitchen\costing\price-lists\Preçário.xlsx
  2. Altere os preços na coluna «Preço s/IVA» É esta a coluna que conta. A coluna «Preço c/IVA» calcula-se sozinha — não a preencha à mão.
  3. Confirme a unidade e o IVA Kg, L ou Unidade — e a taxa de IVA do artigo.
  4. Guarde e feche o Excel Ctrl+S e feche mesmo o ficheiro. Com o Preçário aberto, o Windows não deixa o sistema gravar.
  5. Duplo clique em ATUALIZAR-FICHAS-TECNICAS
    ATUALIZAR-FICHAS-TECNICAS.cmd
  6. Espere pela mensagem de sucesso «Sincronização concluída com sucesso.» As fichas estão atualizadas e pode abri-las.
O passo mais importante Guardar e fechar o Preçário antes de atualizar. É a causa número um de a atualização não avançar.

03Os três botões do sistema

Estão todos na pasta principal. Basta duplo clique.

▶
ATUALIZAR-FICHAS-TECNICAS.cmd Atualiza as fichas com os preços do Preçário. É o que usa no dia-a-dia.
👁
VERIFICAR-FICHAS-TECNICAS.cmd Mostra o que iria mudar, sem alterar nada. Pode usar à vontade, é seguro.
✓
INSTALAR-SISTEMA-COZINHA.cmd Verifica se está tudo em ordem. Use só na primeira vez, ou se algo parecer estranho.
Na dúvida antes de uma atualização grande, corra primeiro VERIFICAR. Mostra-lhe todos os custos novos sem gravar nada.

04Se aparecer um erro

«Existem ficheiros Excel abertos» O sistema diz-lhe quais. Feche-os no Excel e repita. Nada foi alterado — pode repetir sem receio.
«A atualização NÃO foi concluída» Nenhum ficheiro fica a meio: ou muda tudo, ou não muda nada. Antes de cada atualização é guardada automaticamente uma cópia de segurança. Leia a mensagem no ecrã e, se não perceber, contacte o responsável do sistema.

As cópias de segurança ficam guardadas em:

docs\kitchen\costing\backups\price-sync\

05Ingredientes «por resolver»

Por vezes aparece uma lista assim no fim da atualização:

Por resolver (sem preço atribuído — nada foi inventado):
    Guarnições/Húmmus · "Tahine" [UNMATCHED]

Significa que o nome do ingrediente na ficha não existe no Preçário. O sistema não inventa preços: prefere deixar em branco a usar um valor errado que estragaria o custo do prato.

Como resolver:

O artigo existe, com outro nome

  • O mesmo produto está no Preçário com uma designação diferente da que a ficha usa
  • É preciso registar essa correspondência — peça ao responsável do sistema

O artigo não existe mesmo

  • Acrescente-o ao Preçário
  • Use o nome tal como aparece na ficha técnica

06Para lembrar

Já não precisa de fazer

  • Abrir as fichas técnicas uma a uma
  • Atualizar ligações do Excel
  • Aceitar avisos sobre «ligações a outros ficheiros»
  • Escrever preços dentro das fichas
  • Mexer em fórmulas

Nunca fazer

  • Escrever preços diretamente nas fichas técnicas
  • Mudar o nome ou o sítio das pastas internas
  • Apagar o ficheiro .ribbai-root
  • Trabalhar com os ficheiros dentro de um ZIP

07Instalar no seu computador

Só é feito uma vez. Não instala nada no Windows nem pede permissões de administrador.

  1. Feche todos os ficheiros Excel Nos dois computadores, o de origem e o seu.
  2. Copie a pasta RIBBAÍ completa Toda a pasta, de uma vez. Não copie só o Preçário nem só as fichas.
  3. Cole no seu computador Onde preferir — ver caixa abaixo.
  4. Duplo clique em INSTALAR-SISTEMA-COZINHA.cmd Faz a verificação e diz-lhe se está tudo bem.
  5. Confirme a mensagem final Deve ler «SISTEMA PRONTO A UTILIZAR».
  6. Teste com VERIFICAR-FICHAS-TECNICAS.cmd Não altera nada. Se correr bem, está pronto.
A pasta pode ficar onde quiser C:\RIBBAI · D:\RIBBAI · Documentos\RIBBAI · OneDrive\RIBBAI
Funciona em qualquer disco e com qualquer nome de utilizador Windows, desde que a pasta seja copiada por inteiro e as pastas de dentro fiquem como estão.
Se usar OneDrive ou SharePoint Os ficheiros têm de estar descarregados no computador (não «apenas online»), os workbooks têm de estar fechados, e duas pessoas não podem atualizar ao mesmo tempo. Na dúvida, prefira uma pasta local.

Notas para o responsável do sistema

Esta secção não é necessária ao Chefe de Cozinha

O runtime/ não vai no controlo de versões: viaja na cópia da pasta. Antes de transferir, garantir que existe — caso contrário gerar com npm run kitchen:runtime:build (motor, ~215 KB) e npm run kitchen:runtime:node (node.exe portátil, ~82 MB, verificado por checksum oficial).

Depois de qualquer alteração ao motor é obrigatório reconstruir o bundle, senão os launchers continuam a correr a versão anterior.

Comandos de manutenção: npm run kitchen:costing:check (dry-run), kitchen:costing:update (aplica e valida), kitchen:health (health check). Arquitetura completa em docs/kitchen/costing/README.md e documentation/INSTALLATION-GUIDE.md
